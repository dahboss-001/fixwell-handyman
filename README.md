# Fixwell Handyman

A WhatsApp-first handyman and artisan marketplace site for Awka (Anambra) and Aba (Abia), Nigeria.

## Edit the site
All client-editable content lives in the `CONFIG` block at the top of `app.js`:
- WhatsApp number, phone, email, address, hours (placeholders)
- Cities and service areas
- Services and starting prices
- Price guide ranges
- Maintenance plan prices, discounts and features
- Artisan membership plans
- Hero stats and FAQ

## Run locally
Open `index.html` in a browser, or serve the folder with any static server.

## Deploy
Static site, works on GitHub Pages or any static host.
